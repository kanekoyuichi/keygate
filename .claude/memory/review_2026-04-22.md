## バグ

### B1. `cli.py` で `baseline` コマンドが重複登録されている

```python
@main.group()
def baseline_cmd() -> None: ...
# ...
main.add_command(baseline_cmd, name="baseline")
```

`@main.group()` ですでに `baseline-cmd` という名前で登録されている上に、`main.add_command()` で `baseline` という名前でも登録される。
結果：`secretgate baseline-cmd create` も `secretgate baseline create` も両方動く。

**修正**: `@main.group(name="baseline")` を使い、`main.add_command()` を削除する。

### B2. `get_staged_diff()` のエラーハンドリングなし

`subprocess.run` の `returncode` をチェックしていないため、git リポジトリ外で実行すると stdout が空になり「ステージなし」として終了してしまう。ユーザーが状況を理解できない。

**修正**: `returncode != 0` ならエラーメッセージで終了する。

## 仕様乖離

### S1. `scoring.py` の `_DUMMY_PATTERN` が仕様外

仕様書（CLAUDE.md セクション5.4）では「`example`, `dummy`」のみ。実装では `placeholder|fake|mock|sample` まで含まれており、誤って実シークレットを見逃す可能性がある。

**修正**: `dummy|example` のみに限定する（仕様遵守）。

## コードスタイル違反（CLAUDE.md ルール）

### C1. 「what」を説明するコメントが多数

CLAUDE.md ルール「Don't explain WHAT the code does」に違反。

- `cli.py`: `# 1. inline ignore`, `# 2. allowlist`, `# 3. scan`, `# 4. baseline チェック`, `# baseline サブコマンドを main に登録`
- `diff/parser.py`: `# 削除行: 行番号は変化しない`, `# コンテキスト行`
- `scoring.py`: `# rule は最高スコアの1件のみカウント`

**修正**: 全削除する。
